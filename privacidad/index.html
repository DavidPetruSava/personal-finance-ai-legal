Política de privacidad

Última actualización: 5 de noviembre de 2026

Esta página describe el tratamiento de información en el proyecto Personal Finance AI, una herramienta privada desarrollada para uso personal de su titular. No es un servicio financiero ofrecido al público ni una aplicación destinada a que terceros conecten sus cuentas.

1. Responsable y contacto

El proyecto es gestionado por su titular para fines estrictamente personales. Para consultas relacionadas con esta página o con el proyecto: davidsava4@gmail.com.

2. Información que puede tratarse

Cuando el titular autoriza la conexión de una cuenta bancaria, la aplicación puede recibir información de cuentas, saldos y movimientos, como fechas, importes, divisas, conceptos o descripciones y otros datos que la entidad ponga a disposición mediante el servicio AIS. La información concreta depende de la entidad y de los permisos concedidos.

La aplicación no solicita ni almacena las credenciales de acceso a la banca online. La autenticación y autorización se realizan en los canales de la entidad bancaria y del proveedor AIS. Las claves técnicas y tokens necesarios para la integración se mantienen localmente y deben protegerse como secretos.

3. Proveedores y circulación de los datos

La conexión bancaria está prevista a través de Enable Banking Oy, como proveedor de servicios de información de cuentas (AIS), y de la entidad bancaria correspondiente. Los datos bancarios transitan por la infraestructura del proveedor AIS para que puedan entregarse a la aplicación autorizada. Por tanto, no debe entenderse que los datos bancarios nunca salen del ordenador del titular.

Una vez recibidos, el diseño previsto del proyecto es almacenarlos en el equipo local del titular (por ejemplo, en una base de datos SQLite) y procesarlos allí para elaborar clasificaciones, informes y hojas de cálculo. Los modelos de IA previstos se ejecutan localmente mediante Ollama. No se pretende enviar los movimientos a un servicio externo de IA.

Esta web es únicamente un conjunto de páginas informativas estáticas alojadas mediante GitHub Pages. No contiene formularios para introducir datos bancarios ni funcionalidades para recibir movimientos. GitHub puede tratar datos técnicos de acceso y registros de funcionamiento conforme a sus propias condiciones y políticas.

4. Finalidades y permisos

La finalidad es consultar y organizar las finanzas personales del titular. La conexión AIS se utilizará únicamente después de que el titular otorgue la autorización correspondiente y dentro del alcance de los permisos disponibles. El proyecto no inicia pagos ni transferencias y no utiliza servicios de iniciación de pagos (PIS).

5. Conservación y seguridad

Los datos descargados se conservarán localmente mientras el titular los necesite y no los elimine. El titular puede borrar los ficheros y bases de datos locales cuando lo decida. Las claves privadas, credenciales técnicas y tokens no deben publicarse en repositorios, compartirse ni incluirse en copias de seguridad sin protección.

La revocación del consentimiento AIS impide futuras consultas bajo esa autorización, pero no elimina automáticamente los datos que ya se hayan guardado en el ordenador. Esos datos deben borrarse localmente si se desea suprimirlos.

6. Uso personal y consultas

El proyecto está concebido exclusivamente para la gestión de las cuentas del propio titular y no para tratar datos bancarios de otras personas. Las consultas sobre datos tratados por la entidad bancaria o por el proveedor AIS deberán dirigirse también a la entidad o proveedor correspondiente, según proceda.

7. Cambios y contacto
