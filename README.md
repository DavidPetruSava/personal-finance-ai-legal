## Publicación con GitHub Pages

En GitHub, abre **Settings → Pages** y configura:
- **Build and deployment**: Deploy from a branch
- **Branch**: `main`
- **Folder**: `/(root)`

Guarda los cambios y espera a que finalice la publicación.

## Importante

Este repositorio contiene únicamente páginas informativas. No subir aquí claves privadas, certificados PEM, tokens, credenciales bancarias, bases de datos, extractos ni ficheros financieros.
